# GymOS (web app)

Private, offline gym tracker for iPhone. Install it from Safari with **Share → Add to Home Screen**.

- Works fully offline after the first load (service worker).
- All data is stored only on the phone (IndexedDB). No account, no server, no tracking.
- Backups use the same `.gymbackup` format as the native GymOS iPhone app, in both directions.

App URL: https://jleo7358-coder.github.io/gymos-app/
